# Banking Analytics Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive **Banking Analytics Dashboard** built using **Microsoft Power BI**.

The dashboard is designed to analyze banking operations across customers, accounts, transactions, branches, and loans. It converts banking data into interactive KPIs, charts, and business insights to support data-driven decision-making.

The underlying banking database was developed using **MS SQL Server**.

## 📌 Dashboard Pages

### 1. Banking Overview

This page provides a high-level view of the banking business.

**Key KPIs:**
- Total Customers
- Active Accounts
- Total Bank Balance
- Active Loans
- Total Loan Amount

**Visualizations:**
- Branch-wise Total Balance
- Account Type Distribution
- Account Status Distribution

---

### 2. Transaction Analysis

This page analyzes customer transaction activity.

**Key KPIs:**
- Total Transactions
- Total Deposits
- Total Withdrawals
- Total Transaction Amount

**Visualizations:**
- Monthly Transaction Trend
- Transaction Type Distribution
- Top Customers by Transaction Amount

**Current dashboard insights:**
- 37 total transactions
- ₹3.80 lakh total transaction value
- ₹3.57 lakh total deposits
- ₹23,000 total withdrawals

---

### 3. Loan & Customer Analysis

This page focuses on the bank's loan portfolio and customer-level loan exposure.

**Key KPIs:**
- Active Loans
- Total Loan Amount
- Total Loan Payments
- Remaining Loan Amount

**Visualizations:**
- Loan Amount by Loan Type
- Customer-wise Loan Exposure
- Loan Payments by Loan Type
- Customer Loan Details

---

## 💡 Key Business Insights

- Savings accounts represent the largest account category.
- 60% of accounts are currently active.
- Transaction activity is strongly deposit-oriented.
- Customer transaction activity can be compared to identify high-value customers.
- Loan exposure can be analyzed by customer and loan type.
- Branch-wise analysis helps identify differences in account balances.

## 🗂️ Data Model

The Power BI dashboard uses data from the banking database developed in MS SQL Server.

Main tables include:

- Customers
- Accounts
- Branches
- Employees
- Transactions
- Loans
- LoanPayments
- Beneficiaries
- TransactionAudit

A Date Table was also created in Power BI for transaction trend analysis.
